## Why

Need a TikTok-style feed for live auctions to increase engagement. Only layout and pure components are needed for now, no backend integration.

## What Changes

- Create endless vertical scroll feed for auctions.
- Add hamburger menu component.
- Add viewer count indicator.
- Add main media area (video/static image).
- Add interaction card (product image, highest bid/base price, bid button, ranking button, other auctions button).
- Add chatbox for bot messages and user comments.

## Capabilities

### New Capabilities
- `live-auction-feed-ui`: Pure UI components and layout for the endless vertical live auction feed.

### Modified Capabilities

## Impact
- New UI components added. No API or state management impact yet.
