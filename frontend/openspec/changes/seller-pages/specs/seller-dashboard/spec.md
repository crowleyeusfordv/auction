## ADDED Requirements

### Requirement: Seller Navigation Layout
The system MUST provide a layout wrapping all seller pages, containing a sidebar with links to "My Auctions" and "Orders".

#### Scenario: Navigating to seller pages
- **GIVEN** a seller is logged in
- **WHEN** the seller accesses the seller section
- **THEN** they MUST see the sidebar with "My Auctions" and "Orders" links
